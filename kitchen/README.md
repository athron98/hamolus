# Kitchen

Project planning notes kept in one room. These pages are public-facing: anything
written here is safe to show a contributor or a reader who is not in the room.

| Page | What it holds |
| ---- | ------------- |
| [recap.md](./recap.md) | Presentable minutes of a working session |
| [roadmap.md](./roadmap.md) | Direction, priorities, and what is explicitly deferred |
| [planning.md](./planning.md) | Deliberations, open questions, working agreements |
| [todo.md](./todo.md) | Tracked work: todo / doing / done |

The private counterpart lives in `.opencode/` and is not for external reading.
